# 规范 G · 精简背诵版（每章 5–7 页）

用户要求：去掉重复内容，给一份能快速复习的精简资料。完整版已存在，本版只做「考前直接背」的浓缩，**不重复完整版的叙事讲解**。

## 输入
- 骨架：`.epa_work\slices\<cid>_skeleton.json`（KC 列表，含 label/type/importance）
- 课堂实录：`讲义\<章名>-课堂实录.md`（案例 + 老师结论）
- 法条核对：`讲义\<章名>-法条核对.md`（现行规定与更正）
- 完整版知识清单（只用来核对结论，不要整段搬）：`.epa_work\notes\<章名>.html`

## 输出
写文件：`.epa_work\notes-精简\<章名>.html`（目录不存在就建）。只输出**章节片段**（不含 h1/doctype），由上层拼成一本。

结构固定为 4 块（顺序不变，块内用表格，不要大段文字）：

```
<h2>第X章 <章名></h2>

<h3>一、知识点一句话结论</h3>
<p>全章 <N> 个知识点，按学习顺序；「必考/重点」是标签，最后两列是考场最容易错的点。</p>
<table>
<tr><th>编号</th><th>知识点</th><th>一句话结论（是什么/要件/效果）</th><th>易错</th></tr>
… 每个 KC 一行，结论 ≤60 字，易错 ≤30 字 …
</table>

<h3>二、老师课堂案例（结论版）</h3>
<table>
<tr><th>案例</th><th>一句话案情</th><th>结论</th><th>依据</th></tr>
… 每个案例一行：案情 ≤50 字，结论 ≤40 字，依据写条号/司法解释/指导案例 …
</table>

<h3>三、名词解释（背这一列）</h3>
<table>
<tr><th>术语</th><th>定义（≤50 字，可直接写答题卡）</th></tr>
… 15–25 行 …
</table>

<h3>四、必背数字 / 期限 / 比例</h3>
<table>
<tr><th>事项</th><th>数字</th><th>依据</th></tr>
… 10–20 行 …
</table>
```

## 硬性要求
1. **不与其他章节重复**：本章只写本章内容；不要写「答题框架总论」这类通用内容（整体模板由上层统一放一次）。
2. **不重复自己**：案例表里不再解释知识点（知识点表已有）；名词解释不再引案例；数字表只列数字类考点。
3. 浓缩原则：每个 KC 一句话，删掉 Hook、为什么、讲解、课堂原话；只留结论、要件、效果、易错。
4. 案例只保留**老师课上真实讲过的**；无录音的章（劳动争议处理法）改用「PPT 规则构造的案例」，并在表前一句注明。
5. 数字、条号、比例必须与 `讲义\<章名>-法条核对.md` 的现行口径一致（如 13 天法定节假日、20.67、延迟退休 63/58/55、法释〔2025〕12 号等）。
6. 表格单元格内不用换行标签；一句话结论里需要分点时用「①…②…」。
7. 全章篇幅控制在 5–7 页 A4 的量（约 1800–2600 汉字），宁可再删不要超。

## HTML 规则
- 只用 h2/h3/p/table/tr/th/td/strong；禁止 h1/div/span/script/style/doctype。
- 正文禁止裸 `<` `>`；引号用「」。

## 自检
1. 4 块齐全，表格行数符合（KC 数、案例数、名解 ≥15、数字 ≥10）。
2. 有没有重复？——知识点表已讲的，案例表不再解释；名解不举案例。
3. 数字与法条核对表一致？
4. 字节数在合理区间（约 15–30KB）。

最后用 3 行汇报：KC 行数 / 案例行数 / 名解条数 / 数字条数 / 字节数。
