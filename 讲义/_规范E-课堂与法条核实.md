# 规范 E · 逐知识点：老师怎么讲 + 法条依据（联网核实）

你是复习资料的「法条校对员 + 讲课还原员」。目标：让每一个知识点都**既有老师课堂讲解的支撑，又有现行法条的依据**，并指出课件（PPT）与现行规定不一致的地方。

## 输入
1. 骨架切片：`.epa_work\slices\<cid>_skeleton.json`（该章 KC 列表）
2. 提取切片：`.epa_work\slices\<cid>_extract.json`（PPT 逐页原文，用于确认「资料里的说法」）
3. 课堂实录：`讲义\<章名>-课堂实录.md`（**老师怎么讲，只能从这里来**）
4. 现有知识清单：`.epa_work\notes\<章名>.html`（用于确认已有表述、避免重复整段抄写）

## 联网工具（重要）
本机 `web_fetch` 工具不可用（DNS 走代理 fake-IP，报 non-public IP）。请用 **pwsh 调用 curl/Invoke-WebRequest** 取网页：
```
curl.exe -L --max-time 30 -A "Mozilla/5.0" "https://www.court.gov.cn/..." -o out.html
```
或 PowerShell：
```
$r = Invoke-WebRequest -Uri "https://..." -UseBasicParsing -TimeoutSec 30 -Headers @{'User-Agent'='Mozilla/5.0'}
```
可访问的权威站点（实测）：`www.court.gov.cn`、`www.gov.cn`、`www.npc.gov.cn`、`www.mohrss.gov.cn`、`hrss.yn.gov.cn`、`policy.mofcom.gov.cn`。部分站点 403/超时（如 bjcourt、taihe、rst.sc），换源即可。
`web_search` 工具可用，但只返回标题与链接，需要正文就 curl 取。

## 输出（两个文件）

### 文件一：`讲义\<章名>-法条核对.md`
Markdown 表格，一行一个核对项（每章 10–18 行，覆盖本章最容易错、最常考、数字/条号密集的点）：
```
| 知识点 | 资料/PPT 里的说法 | 现行规定与依据（条号 + 要点） | 结论 | 来源 |
|--------|------------------|------------------------------|------|------|
| 无固定期限合同三情形 | PPT 写「连续订立二次…」 | 《劳动合同法》第14条第2款第（三）项；法释〔2025〕12号第10条进一步规定四种「视为连续二次」情形 | 一致，需补司法解释 | https://... |
```
要求：来源必须给**真实可访问的 URL**（官方优先：最高法、全国人大、国务院、人社部）；引用条文要写清**法律名 + 条号 + 款/项**；结论写「一致 / 需补充 / PPT 已过时，应更正为…」。

### 文件二：`.epa_work\notes\<章名>-课堂与法条.html`
只输出 HTML 片段，结构：
```
<h2>知识点逐条：老师怎么讲 + 法条依据</h2>
<p>一句说明：每一条先还原老师课堂上的讲法（来自录音整理稿），再给现行法条依据；课件与现行规定不一致的，单独标「更正」。</p>
<h3>kcX.Y 知识点名</h3>
<p><strong>老师怎么讲</strong>：…（150–300 字，转述老师课堂上对这个知识点的讲法，可摘引原话 1–2 句；标注来源录音，如「（劳动法2. 12:30）」；录音没讲的写「课堂未展开」）</p>
<p><strong>法条依据</strong>：<span class="kp">《X法》第X条第X款：…（要点）</span>；…（1–3 条，条号必须核对过）</p>
<blockquote>更正：…（仅当 PPT/现有资料与现行规定不一致时写；写明「课件写…，现行…」，并给依据；没有就省略这一行）</blockquote>
<span class="tag-must">必考</span>
```
要求：
- **每个 KC 一个 H3**，标题 = 骨架 label 原文（可加少量括注）。
- 「老师怎么讲」只能来自课堂实录，不得编造；录音没讲就写「课堂未展开，以下为法条依据」。
- 「法条依据」必须与核对表一致，条号必须真实；不确定的宁可不写条号，只写规则。
- 「更正」只在确有差异时出现（例如：社会保险法/延迟退休、法定节假日天数、司法解释更新、最低工资标准、生育保险与医保合并、失业保险降费率等）。
- 每 H3 末尾一个四色标签（tag-must/tag-key/tag-freq/tag-info，文字为必考/重点/高频/了解）。

## HTML 硬规则
- 只输出片段：禁止 `<!DOCTYPE>`、`<html>`、`<head>`、`<style>`、`<script>`、`<body>`、`<h1>`、`<details>`。
- 只用 h2/h3/p/ul/ol/li/table/tr/th/td/blockquote/span/strong。
- 正文禁止裸 `<` `>`；引号一律「」；箭头 `→`；不用 ASCII 双引号做引号。

## 必须重点核查的「现行法 vs 课件」清单（按章取用）
- 导论：劳动关系认定依据（劳社部发〔2005〕12号三要件；法释〔2020〕26号、法释〔2025〕12号）；新就业形态 2021 年八部门指导意见、2023 年人社部三项指引（含职业伤害保障试点）。

- 劳动合同法：第14条+法释〔2025〕12号第10条；第19、20条试用期；第47条经济补偿（三倍/12年）；第82条二倍工资+法释〔2025〕12号第6、7条；第87条赔偿金；第66条劳务派遣+《劳务派遣暂行规定》第4条10%；第68、72条非全日制（4小时/24小时/15日）。
