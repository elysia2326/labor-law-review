# 规范 F · 消除模糊表述，改为有依据的确定结论

用户要求：复习资料里**不要出现「带问号/仍在讨论/存疑/未给定论」这类悬空表述**；每个知识点要么给确定结论，要么给出官方/权威依据（法条、司法解释、指导性案例、最高法口径、通说教材）。

## 要改的 vs 不要改的
**要改**（属于「对法律问题不给结论」）：
- 「…后面被加了问号，提示这一层能否成立仍在讨论」
- 「组织从属性？…尚有讨论/独立地位有争议/有学者主张…」
- 「老师留作思考，未给定论」「老师未给答案」「学理上有两种观点，可写…」
- 「是否…仍有争议」「尚待明确」「存疑」「可能成立」（用于法律定性时）
- 「课上未展开」后不接结论的段落

**不要改**（这些是正常的教学设问，不是模糊表述）：
- 每个 H3 开头的 Hook 设问（如「为什么只有前者是劳动关系？」）
- 自测题（checkpoint）里的问题
- 引用 PPT 原文时保留的问号（如课件原文「组织从属性？」），但**必须紧跟一句确定解释**
- 案例的「争点」问句

## 改写规则
1. **能确定的一律给结论**：按现行法、司法解释、最高法指导性案例/典型案例、通说。句式：「结论：……。依据：……（法律名+条号 / 解释名+条号 / 指导案例编号+裁判要点 / 教材名+版次）」
2. **确有不同学理观点的**：只写「通说」与「司法口径」两条确定口径，不写「有人主张…仍在讨论」；句式：「学理通说：……；司法口径：……（依据）。答题以司法口径为准。」
3. **老师课上没给结论的案例**：保留一句客观说明（「老师课上未展开」），但紧接着给出按现行规则的**明确分析结论**，并注明依据。
4. **课件本身写错/过时的**：保留「课件写…」，随后写「现行规定为……（依据）」，不要写成疑问。
5. 新增的权威依据必须真实：能联网就用之前章节的方法（web_search + curl/Invoke-WebRequest）核实，并把来源写进 `讲义\<章>-表述修订.md`；查不到官方来源的，用法律条文原文，不要编造案例编号。
6. 不改动题目、不改动 H3 数量、不改动四色标签数量、不改动章节结构。

## 操作方式（必须这样做）
用 Python 精确替换，逐条断言命中，避免误伤：
```python
import io
p = r'...\notes\<章名>.html'
s = open(p, encoding='utf-8').read()
pairs = [
  ('原文片段（必须在文中唯一存在）', '改写后的片段'),
]
for old, new in pairs:
    assert s.count(old) == 1, ('命中数异常', old[:30], s.count(old))
    s = s.replace(old, new)
open(p, 'w', encoding='utf-8').write(s)
```
- 每次替换后检查：文件仍以 `<h2` 开头、H3 数量不变、`tag-` 数量不变、没有出现裸 `<`。
- 如果原文片段在文中出现多次，先加上下文扩到唯一，再替换。

## 输出
1. 直接改写 `C:\Users\23697\Desktop\劳动法\期末复习\.epa_work\notes\<章名>.html`（原地）
2. 写变更日志：`C:\Users\23697\Desktop\劳动法\期末复习\讲义\<章名>-表述修订.md`，表格：位置（H3 标题/案例编号）｜原文｜改为｜依据（条号/案例号/URL）｜类型（给出结论/更正课件/补司法口径）

## 自检
1. 全章再扫一遍：`问号/存疑/有争议/尚待/未定论/留作思考/两种观点` 这些词是否只剩 Hook、自测、PPT 原文引用？
2. H3 数、标签数与改前一致？
3. 每条新结论都有依据（条号/案例号/教材）？
4. 变更日志条数 = 实际替换条数？

最后用 4–6 行汇报：替换条数、保留的「PPT 原文问号」几处、新增依据类型、H3 数前后是否一致、文件字节数变化。
