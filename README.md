## 怎么用

**手机 / 平板离线看**：把 `打印版/` 里的 PDF 下载到本地，用任意 PDF 阅读器打开即可，不需要联网。每章 PDF 包含：知识清单正文、老师课堂案例精讲、名词解释速查、答题框架、知识点逐条（老师怎么讲 + 法条依据）、法条核对来源、PPT 逐页要点。

**电脑看网页版**：浏览器打开 `EPA/index.html`。网页版比 PDF 多两样东西：
- 右栏「原始幻灯片对照」——每页 PPT 的原图和原文文字，标题旁的 `[页N]` 可点击跳转；
- 「📝 章节测试」标签页——选择题自动判分、辨析/名词解释/案例分析题给参考答案，可导出作答 JSON 做 AI 批改。

**手机上想用网页版**：在电脑上起一个本地服务，手机连同一 WiFi 访问（`python -m http.server 8899 --directory EPA`）。
